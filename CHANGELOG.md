# Changelog

## [2.0.0] - 2026-09-09

A review of the template against Playwright 1.63, `@playwright/cli` 0.1.19, `wico-playwright-agent-skills` 2.0.0 and the current Playwright CI/Docker guidance. Everything the review found is fixed here; the template is meant to be cloned or used via "Use this template", so nothing is published to npm.

### Breaking

- **Node ≥ 22.13** (`engines`), matching `.nvmrc` (22.20) and ESLint 10's floor.
- **No `postinstall` browser download.** `npm install` no longer runs `playwright install`; run `npm run pw:setup` once (CI and the Docker image already have the browsers). `npm ci --ignore-scripts` is what CI and the Dockerfile use.
- **Skills layout.** The hand-vendored `.claude/skills/playwright-cli/` copy is gone; Playwright's own `npx playwright init-skills` installs the official `playwright-cli`, `playwright-trace` and `playwright-component-testing` skills into `.claude/skills/` and `.agents/skills/`. `playwright-e2e` is regenerated by `wico-playwright-agent-skills` 2.0.0 for Claude Code (`.claude/skills/`), Cursor (`.cursor/rules/playwright-e2e.mdc` + `.agents/skills/`), Copilot (`.github/instructions/playwright-e2e.instructions.md` + `.github/copilot-instructions.md`) and Codex (`.agents/skills/`). `npm run skills:sync` regenerates all of it; CI fails on drift.
- **Reporters.** CI produces `list` + `blob` + `github` (one HTML report is merged from the shards by the workflow); locally `list` + `html` that opens only on failure. `npm run report` still opens the last local HTML report.
- **Lint stack majors:** ESLint 10, `@eslint/js` 10, typescript-eslint 8.70, eslint-plugin-playwright 2.11, Prettier 3.9. TypeScript stays 5.x (typescript-eslint supports `< 6.1`).
- **Example spec** uses the `{ tag: ['@smoke'] }` option instead of a title suffix and imports the page object through the `@pages/*` alias.

### Added

- `playwright.config.ts` loads a local `.env` with Node's `process.loadEnvFile()` (no dotenv), sets `timeout`, `expect.timeout`, `actionTimeout`, `navigationTimeout`, `outputDir`, `testIdAttribute`, retains video on failure, and carries commented examples for mobile projects, a `storageState` setup project and `webServer`.
- GitHub Actions: a `lint` job (ESLint, tsc, Prettier, `skills:check`, and a check that the Dockerfile base image equals the installed `@playwright/test` version), a 2-shard test matrix uploading blob reports, and a `merge-reports` job publishing one HTML report. `permissions: contents: read`.
- Scripts: `test:chromium`, `report:merge`, `pw:setup`, `skills:sync`, `skills:check`; Makefile targets `skills-sync`, `skills-check`, `report-merge`.
- `src/pages/components/navigation.component.ts` — a component example used by `HomePage.nav`, with a spec exercising it.
- Workflow `workflow_dispatch` trigger; in-progress runs are cancelled only for pull requests, never on `main`; actions on their current majors (`checkout@v7`, `setup-node@v7`, `upload-artifact@v7`, `download-artifact@v8`).
- Locally, every failing test keeps a trace (`trace: 'retain-on-failure'`); CI keeps `on-first-retry`.
- ESLint's Playwright rules now cover page objects and components too, and `playwright/expect-expect` stays on with `assertFunctionPatterns: ['^expect']` so `page.expectX()` helpers count as assertions; `tsconfig` enables `noUnusedLocals`/`noUnusedParameters`.
- `make docker-test` runs with `--init --ipc=host` and copies the HTML report out of the container to `./playwright-report`.
- `CHANGELOG.md` (this file).

### Fixed

- Dockerfile pinned `mcr.microsoft.com/playwright:v1.58.2-jammy` while the package required `@playwright/test ^1.59` — the browsers inside never matched. It now uses `v1.63.0-noble`, installs with `--ignore-scripts`, and runs as the image's `pwuser` with `CI=1`.
- `.env.example` documented a variable nothing loaded.
- README: title, "Use this template" flow, install steps that match the scripts, the real project structure (four skill packs, `.agents/`, `.cursor/`, Copilot files), CI description, environment variables. AGENTS.md: setup, conventions (tag syntax, alias imports), skills pointers, CI expectations.
- `.gitignore`/`.dockerignore`/`.prettierignore`/ESLint ignores cover `.playwright-cli/`, `all-blob-reports/` and the generated skill trees (whose formatting belongs to their generators).
